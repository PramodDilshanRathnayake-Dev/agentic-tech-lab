# Design System & Mockups - v3.0 CEO-Requirement-Grooming

## Overview
This document outlines the design tokens and UI/UX specifications for the new **CEO Home Page** and **AI Requirements Grooming Modal**, as generated by the @uiux agent.

### High-Fidelity Mockups
- **CEO Home Page**: `artifacts/v3.0/uiux/mockups/ceo_home_page.png`
- **Grooming Modal**: `artifacts/v3.0/uiux/mockups/ceo_grooming_modal.png`

## Design Tokens (Glassmorphism & Neon)

### Color Palette
- **Background Base**: `#0A111F` (Deep Navy/Black)
- **Glass Panel Background**: `#121E31` with 80% opacity and strong blur (`backdrop-blur-md` or `xl`).
- **Accent Cyan (Neon)**: `#00D2FF`
- **Accent Purple (Neon)**: `#B026FF`
- **Text Primary**: `#FFFFFF` (White)
- **Text Secondary**: `#64748B` (Slate)
- **Borders**: `#1E2D4A` (Subtle dark blue/gray for inner panels)

### Typography
- **Primary Font**: `Inter` or `sans-serif`
- **Headers**: Uppercase, bold, tracking-widest (e.g., `tracking-[0.2em]`) for section titles.
- **Body**: Regular weight, 14px sizes for data points.

### Components

#### 1. Glass Panel (Base Container)
- Background: `bg-[#121E31]/80`
- Border: `border border-[#1E2D4A]`
- Rounded Corners: `rounded-xl`
- Shadow: `shadow-[0_8px_30px_rgba(0,0,0,0.5)]`
- Backdrop Filter: `backdrop-blur-md`

#### 2. Glowing Button ("Initiate Grooming")
- Background: Linear gradient from `#00D2FF` to `#B026FF`.
- Border Radius: Pill shape (`rounded-full`).
- Text: White, bold, uppercase.
- Effects: Outer glow (`shadow-[0_0_20px_rgba(0,210,255,0.6)]`), transition on hover.

#### 3. Agent Chat Bubble
- Background: Semi-transparent gray/blue or matching glass panel.
- Border: Thin glowing border (Cyan for PM agent, Purple for system/Architect).
- Avatar: Circular, neon border.

### Layout Details
- **Home Page**: A grid layout (similar to existing v2.0 Dashboard) offering a top-level statistical view (Total Projects, AI Performance) taking prominence over the timeline.
- **Modal**: Centered overlay on top of the dashboard. Contains step indicators at the top (`Input -> Grooming -> Architecting -> Review`).
